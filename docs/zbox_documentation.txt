ZBOX DOCUMENTATION
==================

ZBox as it is today, in the order you meet it: first start, adding an
account, reading, writing, organising, and everything around them.
Every keyboard shortcut is listed in Help > Keyboard Shortcuts (F1),
which is kept in step with the app, so this document names only the
keys it needs.


1. WHAT ZBOX IS
---------------
ZBox is a portable email client for Windows, built for screen reader
users and tested with NVDA and JAWS. There is no decorative chrome,
every control has a name, and every important state is also given as
text, never by colour or bold alone.

ZBox has no speech of its own. Everything it announces is handed to
the screen reader you already run, in your own voice, rate and
settings.

Announcements are automatic: ZBox speaks while a screen reader runs
and stays silent otherwise. One switch in Settings, Accessibility and
Shortcut Keys, turns all of its speech on or off. Messages that only
report what happened appear as small notices that close by
themselves and never take focus.

Mail is read over IMAP and sent over SMTP through the Himalaya
command-line mail client, which ships inside the ZBox folder.
Outlook.com, Hotmail, Live and MSN accounts are the exception: they
work through Microsoft Graph, Microsoft's own mail service for apps
(section 3).

The whole folder is the app. There is no installer, nothing is added
to the registry, and nothing is written outside the folder. Put it on
a USB stick, an external drive or your desktop.

This is a testing beta. Things will break, and reporting them is what
this build is for (see section 17).

Source code and releases: https://github.com/iqdz/ZBox


2. FIRST START, STEP BY STEP
----------------------------
1. Unzip the ZBox folder anywhere and run ZBox.exe.
2. The licence appears first. Read it, including the third-party
   sections, check I Agree and press Next. I Disagree closes ZBox and
   removes what that run had created, so nothing is left behind.
3. ZBox asks you to set a master password. Set one, and write it down
   somewhere safe. It is never stored, so it cannot be recovered. See
   section 12 for what it protects.
4. The New Account wizard opens. Section 3 walks through it.

ZBox also offers to put a shortcut on your Desktop. A shortcut
records the exact folder, so if you move ZBox later, create it again
from Settings, System tray and window.

A folder moved from another computer, with accounts already set up,
skips these steps and asks for the master password instead.


3. ADDING AN ACCOUNT
--------------------
File > New > Email Account (Ctrl+Shift+N) opens the wizard.

1. The first page says which providers work. Read it and press Next.
2. Type your name and your email address.
3. Type the login email and the password. The login email is usually
   the same as the address; if your provider signs you in with a
   different one, enter that here. A different sending address can be
   set later in Account and Identities Settings.
4. The server page is filled in for providers ZBox knows. Every field
   stays editable. For any other provider, its help pages list the
   IMAP and SMTP servers, ports and encryption.
5. Press Test Connection. It checks the settings without saving the
   account, and says how many messages it found in Inbox.
6. Review the summary and press Finish.

Gmail
Gmail refuses your normal Google password in a mail program. Use a
Google app password:
1. Open https://myaccount.google.com/security and turn on 2-Step
   Verification. App passwords are not offered until it is on.
2. Open https://myaccount.google.com/apppasswords and sign in if asked.
3. Create an app password named ZBox. Google shows it once, as 16
   letters in groups of four. Copy it.
4. Remove the empty spaces from it, so it is 16 letters with no spaces.
5. Paste it where the wizard asks for the password.
If the page says app passwords are not available, 2-Step Verification
is still off, or the account is a work, school or Advanced Protection
account that does not allow them. Changing your Google password
cancels every app password: create a new one and enter it in Tools >
Account and Identities Settings, in the New password field. Help > About ZBox has a
button that opens Google's own instructions.

Outlook.com, Hotmail, Live and Microsoft 365
These accounts sign in with your Microsoft account, not a password.
On the wizard's Login page, choose Microsoft account as the sign-in
method; it is chosen for you for Outlook.com, Hotmail and Live
addresses. Then press Sign in with browser, finish signing in on
Microsoft's page, and return to ZBox. Or press Sign in with a code,
open the address ZBox shows on any device, and enter the code. The
server settings are filled in for you. Some work or school accounts
need their administrator to approve ZBox once before it can sign in.
If Microsoft later asks you to sign in again, ZBox says so: open
Tools, Account and Identities Settings, and sign in there. An
existing account can switch to Microsoft sign-in there too.

Outlook.com, Hotmail, Live and MSN accounts work through Microsoft
Graph instead of IMAP and SMTP, so IMAP need not be turned on in
Outlook.com. Their new mail is checked every 20 seconds. Large
attachments are uploaded in pieces; an encrypted or signed message
must stay under about 3 MB. Such an account added before this
version signs in once more in Account and Identities Settings.
Microsoft 365 work and school accounts still use IMAP and SMTP.

Other providers
Anything with plain IMAP and SMTP should work with its normal password
or an app password: Yahoo, Fastmail and Apple (each needs an app
password), your own server, or a work account that allows it. Proton
Mail needs the Proton Mail Bridge app running on the same computer.


4. THE MAIN WINDOW
------------------
The Mail tab is always first and cannot be closed. It has three
panes, and F6 moves between them. Tab and Shift+Tab also move between
the three panes and stay inside the Mail tab. Ctrl+Y, or View >
Folders > Go to Folder List, goes straight to the folder list.

1. Accounts and Folders, a tree. Enter on a closed account or folder
   opens it, like Right arrow. Unified Folders come first if you
   have set any up, then one branch per account with its Inbox, Sent,
   Drafts, Trash, Junk, Archive and any other folders on the server.
2. Messages, the list, with Status, From, Subject and Date columns.
   Status says Unread in words. Conversations are grouped into
   threads, collapsed by default and showing how many messages they
   hold. The screen reader hears only each row's cells, such as the
   sender, the subject and the date, without the column names before
   them. Settings, Show column headers in the message list, shows
   the header row again.
   View > Columns adds or removes columns: Recipient, Correspondents,
   Received, Size, Attachments, Priority and Junk Status, besides the
   four above. The choice applies to every message list.
   View > Sort By sorts by Date, Received, Star, Order Received,
   Priority, From, Recipient, Correspondents, Size, Subject, Read,
   Junk Status or Attachments, descending or ascending, and switches
   between Threaded and Unthreaded. Correspondents is the recipient
   in Sent and Drafts, and the sender everywhere else.
3. Message, a reader that previews the selected message without
   marking it read.

Opening a message, writing one, searching, or opening a conversation
each adds a tab. Ctrl+Tab and Ctrl+Shift+Tab move between tabs, and
Ctrl+W, Ctrl+F4 or Escape closes the current one and returns to the
list. The status bar reports loading, counts and results.

The Menu key, Shift+F10 or a right click opens a context menu on the
tree or the list. On an account it offers Account and Identities Settings, Mute,
Pause Automatic Checking, Enable or Disable, Set as Default Account,
Remove, Refresh, and New Folder. On a folder it adds Rename, Delete,
Subscribe or Unsubscribe, and Empty Trash or Empty Junk where they
apply. Empty Trash is on each account's trash folder, whatever the
server calls it, such as Deleted or Deleted Items, and on Unified
Folders' Trash, where it empties the trash of every enabled account
after one confirmation.


5. READING MAIL
---------------
1. Arrow through the list. The reader pane previews each message
   without marking it read.
2. Press Enter or Space to open a message in its own tab. It opens
   with focus in the message body and is marked read.
3. On a collapsed thread, Enter opens its newest unread message, and
   Ctrl+Shift+Page Down and Ctrl+Shift+Page Up then move through the
   rest of the thread in the same tab. Right arrow shows the thread's
   messages as rows without opening any; Left arrow collapses it.
4. Ctrl+Shift+O opens the whole thread in one tab as a conversation:
   a list of its messages with the selected one's body underneath.
5. Ctrl+Shift+T shows messages related to the selected one across
   every folder of that account, found by their threading headers.

Headers
From, To, Cc, Date and Subject sit above the body, outside it, so the
sender's styling cannot hide them. Focus lands in the body; the
headers are one Shift+Tab away. They can be turned off in Settings.
Ctrl+U announces the sender's name and address, and Ctrl+Shift+U also
copies the address. Both use a short dialog that closes by itself,
because the status bar is only spoken if your screen reader reports
it.

HTML and Text view
HTML is the default. It shows the message as sent, through Microsoft
Edge WebView2, prepared so the screen reader reads the message and
nothing else: the page is named by the subject, the reading cursor
starts at the top of the message, and ZBox's own keys, F6 included,
keep working inside the page. Ctrl+B switches the open message to
Text view, plain text in an ordinary read-only field, and back.
Settings can make Text the default, or switch HTML to the legacy
MSHTML engine, which some screen readers read more predictably.

Remote content
Images, styles and fonts that a message would fetch from the internet
are blocked, because they tell the sender when and where you opened
it. A notice above the message says what was blocked. Its buttons
show the remote content for this message (also Ctrl+Shift+I), or
always allow this sender. Pictures attached to the message always
show. See section 11.

Attachments
An open message lists its attachments with name, format and size.
Save one, or Save All into the attachments folder chosen in Settings.

Zoom
Ctrl+Shift+= and Ctrl+Shift+- change the message font size, and
Ctrl+Shift+0 resets it. Settings can also set a reading font.

Saved messages and printing
File > Save Message As (Ctrl+S) saves the open message as an .eml
file. File > Open Saved Message opens an .eml file read-only. Print
(Ctrl+P) and Print Preview (Ctrl+Shift+P) use the standard Windows
dialogs.


6. WRITING MAIL
---------------
1. Ctrl+N opens a new message in its own tab, from the account
   selected in the folder tree, or from the default account when a
   unified folder is selected. Reply (Ctrl+R), Reply All (Ctrl+Shift+R)
   and Forward (Ctrl+L) open one filled in from the message. Reply
   goes to the message's Reply-To address when it has one, and replies
   stay in the same conversation for the recipient.
2. Choose the From account, fill in To, Cc, Bcc and Subject. As you
   type in To, Cc or Bcc, ZBox suggests the addresses you have sent
   to (new messages, replies and forwards) and the contacts you put
   in the address book; mail you receive adds nothing. The most
   used come first, and older sends count for less. Down Arrow opens
   the suggestions: Enter or Tab inserts one, Escape goes back,
   Backspace goes back and deletes a character, and Shift+Delete
   removes the address from the address book. A group's name fills
   in all its members.
3. Write the body. Formatting is on the Compose and Format menus and
   on keys such as Ctrl+B bold, Ctrl+I italic and Ctrl+K link.
   Ctrl+Shift+K says what formatting is at the caret.
4. Check spelling with Ctrl+Shift+F7. The Spell Check dialog offers
   suggestions, Replace, Replace All, Ignore and Add to Dictionary.
5. Attach files with Ctrl+Shift+A. Files are sent with their real
   type, so images and PDFs preview for the recipient.
6. Preview (Ctrl+Shift+P) shows the message as the recipient will
   read it, and the HTML that will be sent.
7. Send with Ctrl+Enter or Alt+S.

Drafts save themselves on a timer while you write (Settings, Draft
autosave interval), and Ctrl+S saves one at any time. Closing a tab
with unsaved writing asks whether to save a draft, discard it, or
keep editing. A reply you never typed into closes without asking.

Each account can have a signature, written in a formatted editor
(Compose > Edit Signature, or Account and Identities Settings), with a plain text
version sent alongside it. It is added to new messages, replies and
forwards, and Ctrl+Shift+S inserts it by hand.


7. ORGANISING MAIL
------------------
Every action below works on all selected messages at once
(Shift+Up and Down, or Ctrl+A for all), and on a whole thread when
used on a collapsed thread row. ZBox says how many were done, and
only shows a dialog when something did not work.

- Delete moves messages to Trash. Shift+Delete deletes them
  permanently after a confirmation. In an open HTML message the
  screen reader usually keeps plain Delete for itself; Ctrl+Delete or
  Ctrl+D moves the message to Trash there instead. Delete and
  Shift+Delete act on messages only in the message list, the search
  results and an open message; in a text field they edit text as
  usual.
- Archive moves them to the account's archive folder (on Gmail, All
  Mail).
- Move To and Copy To, in the list's context menu, list the account's
  own folders. M and C open the same menus straight from the list, and
  Shift+M opens a box where you type part of a folder name to move the
  selected message(s) there.
- Mark Read, Unread, Flagged, Junk or Not Junk, from Message > Mark.
- Watch Thread and Ignore Thread, and View > Threads to show all,
  watched or ignored threads.
- Undo (Ctrl+Z) takes back the last Delete, Archive, Mark as Junk,
  Mark as Not Junk or move.

In the message list, the single keys S (flag), A (archive), J (junk),
Shift+J (not junk), W (watch), K (ignore), M (move to), Shift+M (move
by folder name) and C (copy to) act at once. They are on by default
and can be turned off in Settings.

Folders can be created, renamed, deleted, subscribed and unsubscribed
from the tree's context menu. File > Empty Trash and the folder menu's
Empty Junk delete everything in them after a confirmation; on Unified
Folders' Trash, Empty Trash empties every account's trash at once. By default
anything that has sat in Trash or Junk for 30 days is removed once a
day (Settings, Auto-purge).

Message Filters (Tools > Message Filters) are rules per account that
test From, To and Subject, then mark read, flag, or move to a folder.
They run on new Inbox mail as it arrives, and Run Now applies them to
a folder's existing messages.


Ctrl+Z undoes the last Delete, Archive or Junk action in the message
list, the search results, the folder tree and an open message, in
Text and HTML view. It is not a menu shortcut, so in a text field
Ctrl+Z only undoes typing.

8. CHECKING FOR NEW MAIL
------------------------
1. Each account keeps its own connection open and is told by the
   server the moment new mail arrives. The folder on screen is also
   checked regularly in the background.
2. F5 checks the current account now, and Shift+F5 all accounts.
3. New mail plays a sound and shows a Windows notification. Both can
   be turned off in Settings, and Tools > Mute Account silences one
   account.
4. If an account cannot be reached, ZBox says so and pauses its
   automatic checks for a few minutes, longer each time, so one
   unreliable server cannot slow the others.
5. Tools > Pause Automatic Checking stops ZBox contacting an account on
   its own. Its downloaded mail still opens, and F5, sending and
   deleting still reach the server.
6. Tools > Disable Account stops all contact until it is enabled
   again. The account stays in the tree, marked disabled.

Block This Sender
In an Inbox or Junk, the message list's context menu offers Block
This Sender. It moves that sender's messages in the list and in the
account's Inbox to Trash at once, and adds a message filter that
marks their new mail read and moves it to Trash too. For a post that
came through a mailing list, only that member's posts to that list
are blocked, never the whole list. Your own addresses are never
blocked. In Trash, Unblock This Sender removes the filter and moves
that sender's messages there back to the Inbox; Undo works for both.
The filter also appears in Tools > Message Filters, where it can be
edited or removed.

Offline
File > Offline > Work Offline shows the last synced copy of the Inbox
and the Archive instead of the server; for Gmail the Archive is All
Mail. Only those two folders are kept for offline use. Every other
folder is always read from the server, with nothing kept on disk;
their message lists are remembered in memory while ZBox runs and
refreshed every two minutes, so they open at once, and the live list
follows a moment later. Synchronize Now downloads the most recent
messages of the Inbox and the Archive for the selected account.
Settings, Clear message cache on moving away from Inbox, off by
default, deletes a message's offline copy and saved body as soon as
it leaves the Inbox or the Archive, also when it was deleted or moved
somewhere else, such as on a phone. Nothing is ever deleted from the
server.

System tray
ZBox shows an icon in the notification area with the unread count.
Settings can minimize or close ZBox to the tray, keep it maximized,
and start it with Windows. File > Exit (Ctrl+Shift+Q) and the tray
icon's Quit always really quit.


ZBox reads which folders your server marks as Sent, Drafts, Trash,
Junk and Archive (Gmail's All Mail for Archive), in any language,
and remembers them for each account. A folder you set in Account
Settings still comes first.

While an instant-sync (IDLE) connection is live, the Inbox it
watches is not checked every 20 seconds, but still at least every
2 minutes.

9. SEARCH
---------
Edit > Find Messages (Ctrl+Shift+F) opens the Search tab. In tab
order: Search for, the words; Look in (All, Subject, From, To or
Body); Account; Folder, which with one account chosen also lists that
account's own folders; Date (Any time, Today, Yesterday, Last 7 days,
Last 30 days, This year, or Custom range, with From date and To date
typed as year-month-day and an optional time such as 14:30); Unread
only; Flagged only; Has attachment; and Search. Enter runs the search
from any of them. The words may be left empty to search by the other
choices alone. Has attachment is checked by ZBox itself, so a search
with it takes longer.

The number found is announced and the cursor lands on the first
result. The results list works like the Inbox list: the same columns,
context menu, single keys and bulk actions, each acting on the
account and folder the message came from. A deleted or moved message
leaves the results at once. Watch Thread, Ignore Thread and Open
Message in Conversation are not offered there, as results are not
grouped by thread. Enter opens a result in its own tab.


10. ADDRESS BOOK
----------------
Tools > Address Book (Ctrl+Shift+B) holds contacts with name, email,
phone and notes. Import and export use vCard (.vcf) or CSV. Groups
work as mailing lists: typing a group's name in To, Cc or Bcc fills in
all its members. Message > Add Sender to Address Book adds the sender
of the selected message.

Contacts added here by hand, imported, or added with Add Sender are
suggested when you write (section 6). Addresses kept from older
versions that you never wrote to stay here, but are suggested only
once you write to them or save them here again.


11. PRIVACY, CONTENT BLOCKING AND JUNK RULES
--------------------------------------------
All of this is in Tools > Privacy and Content Blocking.

Remote content blocking is on by default (section 5). Scripts, frames
and embedded objects are removed from every message, always.

The ad and tracker blocklist is the second layer. When you do load a
message's remote content, or allow a sender, anything from a known
advertising or tracking domain still stays blocked. The list is
merged from public sources (StevenBlack hosts and EasyPrivacy),
updated daily in the background, and has an Update Now button.

Junk mail rules are off by default, and nothing in them guesses.
- Mark as Junk puts the sender on a blocked list, except mailing list
  mail and mail from your own addresses.
- Mark as Not Junk returns the message to where it came from, and puts
  the sender on a never-junk list, which always wins.
- With the rules on, new Inbox mail from a blocked sender shows
  Blocked Sender in the Status column, or moves to Junk if you choose.
- Links in new Inbox mail are checked against a public list of known
  phishing domains (Phishing.Database). A match shows Possible
  Phishing and is never moved.
Each list has a Remove button. Your provider's own spam filtering
still runs as before.


12. SECURITY, AND MOVING ZBOX TO ANOTHER COMPUTER
-------------------------------------------------
Account passwords are encrypted on disk. On the computer you set ZBox
up on, Windows itself holds the key, which is why ZBox opens without
asking. That key does not travel with the folder.

The master password is what lets the folder open its saved passwords
on another computer. So:
1. Set a master password (Settings, App and Data Security, Master
   password) before you move the folder.
2. On the new computer ZBox asks for it once, then opens normally
   there from then on.
3. Without one, every account has to be signed in to its server again
   on the new computer.
The master password is never stored and cannot be recovered. Write it
down.

ZBox also recognises each computer, and locks and asks for the master
password on one it has not seen before, even if Windows would have let
it through.

App lock
Settings, App and Data Security, Lock ZBox when it is fully quit,
makes ZBox ask for an unlock method at every start. Unlock methods can
be a passkey through Windows Hello, a FIDO2 security key, or the
master password. A passkey or security key only unlocks the app; the
master password is still the only thing that opens the saved passwords
on another computer.

Import and export
Tools > Export Accounts and Settings writes a file you can import on
another copy of ZBox. Passwords are never exported, so each imported
account needs its password entered once in Account and Identities
Settings.

End-to-end encryption, OpenPGP
Tools > OpenPGP Key Manager keeps your own OpenPGP keys and your
correspondents' public keys, one line per key. New Key Pair makes a
key for one of your identities: ECC (Elliptic Curve), the default,
or RSA 3072 or 4096, expiring in three years or never. Import
OpenPGP Key File and Import Key(s) From Clipboard read public keys,
secret keys and secret key backups; a secret key with its own
passphrase asks for it once. Export Public Key To File and Copy
Public Key give your public key to others. Backup Secret Key To File
saves your secret key in a file protected by a password you choose;
ZBox reads such a backup back, and other OpenPGP programs need it
decrypted first. Key Properties shows the fingerprint, and sets your
acceptance of a correspondent's key, or whether your own key is a
personal key. Revoke Key and Delete Key ask first.
Your secret keys are kept in the secret store, under the master
password, and the key list in the data folder, encrypted. Nothing is
kept outside the ZBox folder.

A message ZBox cannot decrypt says so instead of showing an empty
page. Its text says the message cannot be decrypted and why: the secret
key is not available, the passphrase was not entered, OpenPGP is not
available in this copy, or the message could not be fetched. When the
sender hid the subject, it reads Encrypted Message, in the message list
too, until the message is opened and decrypted.


Private mode (Settings, App and Data Security, or the key
Windows+Ctrl+Shift+P from any program) is for using ZBox from a USB
drive on a computer that is not yours. It needs a master password,
asks for it, and warns before it starts. While it is on, messages
are read from the server and kept in memory only: no offline copies,
saved messages or debug logs, and Work Offline is not available.
Opened attachments and the browser data of HTML mail are deleted when
ZBox closes. Closing also ends every program ZBox started, empties the
clipboard, and stops trusting the computer unless private mode was
turned on from it. If the drive is lost, only encrypted files are
left on it.

Limits of private mode: Windows still keeps records no program can
remove, such as its list of USB drives, the page file, and
antivirus and network logs. A program that was already open when it
took an attachment cannot be told apart from your other work and is
not closed. Close every opened attachment yourself before closing
ZBox, above all those opened with Windows' own programs such as
Notepad or Windows Media Player, which cannot always be ended
without extra permissions.

S/MIME: Tools, S/MIME Certificate Manager imports your own
certificate with its private key (a .p12 or .pfx file, with its
password) and correspondents' certificates (.cer, .crt, .pem or
.der). Signed and encrypted S/MIME mail is read like OpenPGP mail,
with its status above the message. A signature is trusted when its
certificate comes from an authority Windows trusts and matches the
sender's address. Certificates from valid signatures are kept for
later.

The browser data of HTML mail is kept in the ZBox folder
(data\cache\webview2), not in Windows' Local AppData, and the
thread, junk and pending delete records are encrypted like the
address book.

13. SETTINGS
------------
Tools > Settings opens with focus on a list of categories. Up and
Down Arrow move through it, and Ctrl+Tab and Ctrl+Shift+Tab switch
category from anywhere in the dialog. The categories:
- General: interface language, debug logging (one log per launch in
  data\logs), the attachments folder, the draft autosave interval,
  the system tray and window (minimize or close to the tray, stay
  maximized, run when Windows starts, create a desktop shortcut),
  and updates.
- Personalization: interface theme (Follow system, Light, Dark,
  Midnight blue, Warm dark, Soft contrast), message headers, font
  size and reading font, default view (HTML or Text), HTML engine and
  WebView2 runtime. Language and theme take effect after a restart,
  which ZBox offers to do.
- Accessibility and Shortcut Keys: first the switch for all of
  ZBox's speech, then how long ZBox quiets the screen reader while an
  HTML message opens, how long it waits before focusing the page, how
  long its own announcements stay up, the single-key list shortcuts,
  and the list's column headers.
- Maintenance and Cleanup: Clear message cache on moving away from
  Inbox (off by default), Trash and Junk auto-delete, and the offline
  cache clean-up. Tools > Cache Clean Up Configuration opens this
  category.
- Sounds and Notifications: sounds on or off, desktop notifications,
  and the sound theme. A sound theme is a folder of .wav files in
  data\sounds; any file it lacks falls back to the default sound.
- Security: app lock, unlock methods, master password, private mode.
- About ZBox, with its Contact button. Help > About ZBox opens this
  category.
Times and intervals are chosen from lists of real values, in seconds,
minutes and days.

Account and Identities Settings (Tools > Account and Identities
Settings) holds each account's name, addresses and extra identities, a
new password, signature, junk folder, server settings, and whether it
is muted, checked automatically, disabled or the default. Remove
Account removes it from ZBox and deletes its local copies and saved
passwords; mail on the server is not touched.

Each extra identity has its own dialog: Add Identity or Edit Identity.
Below its display name and address are six check boxes, each followed
by its own fields, which stay disabled until the box is checked. An
unchecked box means the identity uses the account's own setting.
- Use its own signature. Checked with an empty signature means the
  identity sends with none. Edit Signature opens the formatted editor.
- Use its own Reply-To address.
- Always Cc these addresses, and Always Bcc these addresses. They are
  put into the Cc and Bcc fields when you compose from that identity,
  so you can read or remove them before sending.
- Use its own Drafts and Sent folders.
- Use its own outgoing server: server, port, encryption, login name
  and password. Test Outgoing Server signs in to check them. The login
  name defaults to the identity's address.
Changing From in the composer switches to that identity's signature
while the message is untouched, and says so, together with any Cc or
Bcc change.


14. MENUS
---------
File: New (Message, Email Account), Open Saved Message, Close, Save
Message As, Get New Messages for (All Accounts, Current Account),
Offline (Work Offline, Synchronize Now), Print, Print Preview, Exit.

Edit: Undo, Select All, Find Messages.

View: Folders (All, Unified, Jump to Inbox Messages List, Configure
Unified Folders), Sort By (Date, Subject, From, Descending, Ascending),
Threads (All, Watched, Ignored, Expand All, Collapse All), Load More
Messages, Switch Between Text and HTML View, Show Remote Content in
This Message, Message Zoom.

Message: Reply, Reply All, Forward, Archive, Delete, Delete
Permanently, Mark (Read, Unread, Flagged, Junk, Not Junk), Watch
Thread, Ignore Thread, Open Message in Conversation, Show Related
Messages, Add Sender to Address Book, Announce Sender, Announce Sender
and Copy Address.

Compose (in a compose tab): Send, Save Draft, Attach File, the
formatting commands, Insert Link, Formatting Here, Check Spelling,
Next Misspelling, Add Word to Dictionary, Insert Signature, Paste as
Quotation, Word Count, Preview, Edit Signature, and two diagnostics.

Tools: Account and Identities Settings, Mute Account, Pause Automatic Checking,
Disable Account, Remove Account, Address Book, Message Filters, Import
Accounts and Settings, Export Accounts and Settings, Cache Clean Up
Configuration, Privacy and Content Blocking, Settings.

Help: Keyboard Shortcuts (F1), Updates (Check for Updates Now,
Update Settings, Open the Releases Page), About ZBox.

Unified Folders combine one folder type, such as Inbox, from every
account into a single list. Choose them in View > Folders > Configure
Unified Folders. Ctrl+Shift+J, or View > Folders > Jump to Inbox
Messages List, goes to the default Inbox with the cursor on its top
message: the unified Inbox in Unified view, otherwise the default
account's Inbox. ZBox opens there at startup too.

About the translations
The current translations were made mainly with generative
translation, not by native translators. They will have mistakes,
wording that sounds unnatural, and terms your own screen reader or
other programs say differently. If you speak one of these languages,
fixes are very welcome: propose better wording, or report anything
wrong or unclear, by email to harith@gvoice.org. Say which language,
where in ZBox the text appears, what it says now, and what it should
say.

More languages
More languages will be added in future versions. You can also make
one yourself. Each language is a folder in data\lang holding a plain
text .lang file:
1. Copy the en folder, and rename the copy and the en.lang file inside
   it to your language code, for example nl and nl.lang.
2. Change only the text to the right of each equals sign. The notes at
   the top of the file explain the rest.
3. Anything not yet translated is spoken in English rather than left
   silent, so a part-finished file is safe to use.
4. Send the finished file to harith@gvoice.org to have it included in
   ZBox for everyone.

18. UPDATES
-----------
ZBox can find, download and install new versions by itself. The
choices are in Settings, in the Updates group at the end, and in
Help > Updates > Update Settings.

The automatic check
When Check for updates automatically is on, ZBox looks for a newer
release on GitHub at most once a day. It only checks while ZBox is
idle: no key pressed for ten minutes and no message open. It never
checks while you work offline. The check sends nothing but ZBox's
version number: no account, address or other detail. A check that
fails is never announced; it is simply tried again later.

When an update is found
Ask me: ZBox shows the new version and its release notes, with Yes,
update now and Remind me later. Yes downloads the update with a
progress bar you can cancel, then closes ZBox, installs the update and
starts the new version. If a message is still unsent, you are asked
first, and choosing to keep editing leaves the update to be installed
when you next exit ZBox. Remind me later asks again the next day.

Download and install silently: ZBox downloads the update in idle time
and installs it the next time you fully exit ZBox, with File > Exit.
Nothing is installed while you are working.

What an update never touches
An update replaces only ZBox's own program files: ZBox.exe,
apps_files, the himalaya folder, and the language and sound folders
the new version ships. Your accounts, passwords, settings, mail, logs,
custom sound themes and any language you added yourself stay as they
are. Every download is checked against the size and checksum the
release gives, and comes only from ZBox's own GitHub releases.

If the new version fails to start
The previous version is kept in data\update. If the new ZBox does not
start within a minute, the previous version is put back and started
by itself, and ZBox tells you the update was undone. A record of each
install is written to data\logs\update_apply.log.

Updating by hand
Help > Updates > Check for Updates Now checks at once. Help >
Updates > Open the Releases Page opens the download page in your
browser. To update by hand, exit ZBox, then copy the new version's
files over your ZBox folder. Your data folder is kept.
