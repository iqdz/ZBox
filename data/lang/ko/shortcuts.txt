일반
F6: 창 사이 이동
Ctrl+Tab: 다음 탭
Ctrl+Shift+Tab: 이전 탭
Ctrl+W 또는 Ctrl+F4: 현재 탭 닫기
Esc: 메시지 목록에 포커스가 있고 글타래가 펼쳐져 있으면 그 글타래를 접습니다. 그렇지 않으면 현재 탭(메시지, 저장된 메시지 또는 작성 중인 메시지)을 닫습니다. 저장하지 않은 변경 사항이 있으면 먼저 묻습니다
애플리케이션 키 또는 Shift+F10: 포커스가 있는 목록이나 트리 항목의 컨텍스트 메뉴 열기
F1: 키보드 단축키, 이 페이지
Ctrl+Shift+Q: 종료. 설정에서 "닫으면 시스템 트레이로"가 켜져 있어도 항상 실제로 ZBox를 종료합니다(이 설정이 켜져 있으면 창의 닫기 단추, Alt+F4, 메일 탭의 Ctrl+W는 종료하지 않고 트레이로 숨깁니다. 트레이 아이콘의 종료도 항상 실제로 종료합니다)
Ctrl+Shift+Delete: 오프라인 메시지 캐시 지우기. ZBox의 로컬 사본만 지우며 서버에서는 아무것도 지우지 않습니다(도구 > 캐시 정리 설정에도 단추가 있습니다)

메일
Ctrl+N: 새 메시지
Ctrl+Shift+N: 새 메일 계정
F5: 현재 계정의 메일 받기
Shift+F5: 모든 계정의 메일 받기
Ctrl+Shift+J: 받은 편지함 메시지 목록으로 이동
Ctrl+Y: 폴더 목록으로 이동
폴더 목록에서 닫힌 계정이나 폴더에서 Enter: 오른쪽 화살표처럼 펼칩니다
Ctrl+Shift+B: 주소록
Ctrl+Shift+F: 메시지 찾기
Ctrl+Shift+T: 관련 메시지 보기

메시지 목록
Delete, Shift+Delete, 보관, 별표 켜기/끄기, 스팸/스팸 아님으로 표시, 이동, 복사는 접힌 글타래 행에서 사용하면 모두 글타래의 모든 메시지에 적용됩니다. 메시지 하나에만 적용하려면 먼저 글타래를 펼치세요(오른쪽 화살표 또는 Enter/Space)
Ctrl+A: 모든 메시지 선택
Ctrl+Shift+L: 메시지 더 불러오기
Delete: 선택한 메시지를 지운 편지함으로 이동
Shift+Delete: 선택한 메시지를 영구 삭제
Ctrl+Z: 마지막 삭제, 보관, 스팸/스팸 아님 표시 실행 취소
S: 선택한 메시지의 별표 켜기/끄기
A: 선택한 메시지 보관
J: 선택한 메시지를 스팸으로 표시
Shift+J: 선택한 메시지를 스팸 아님으로 표시
W: 글타래 주시. 선택 항목이 속한 글타래의 주시를 켜고 끕니다(메시지 메뉴와 오른쪽 클릭에도 있음)
K: 글타래 무시. 이 글타래의 무시를 켜고 끕니다(메시지 메뉴와 오른쪽 클릭에도 있음)
M: 선택한 메시지 이동 -- 폴더가 담긴 이동 메뉴를 엽니다
Shift+M: 폴더 이름의 일부를 입력해 선택한 메시지 이동
C: 선택한 메시지 복사 -- 폴더가 담긴 복사 메뉴를 엽니다
위의 S, A, J, W, K는 기본적으로 켜져 있으며 설정에서 끌 수 있습니다(켜져 있으면 메시지 목록의 첫 글자 탐색보다 우선합니다)
위의 M, Shift+M, C도 같은 설정을 따릅니다
접힌 글타래에서 Enter 또는 Space: 그 글타래에서 가장 최근의 읽지 않은 메시지(모두 읽었다면 가장 최근 메시지)를 한 탭에 단일 메시지로 엽니다. 그다음 Ctrl+Shift+Page Down과 Ctrl+Shift+Page Up으로 두 번째 메시지를 열지 않고 글타래의 나머지를 이동합니다. 일반 메시지에서는 평소대로 엽니다
접힌 글타래에서 오른쪽 화살표: 아무것도 열지 않고 메시지를 목록으로 보여 줍니다. 그다음 각각의 Enter 또는 Space로 하나씩 엽니다
Ctrl+Shift+O: 대화에서 메시지 열기. 전체 글타래를 한 탭에 메시지 목록과 그 아래 선택한 메시지의 본문으로 보여 줍니다. 화살표 키로 목록을 이동하며 하나씩 읽고, 행에서 Enter를 누르면 그 메시지만 전체 탭으로 엽니다. Thunderbird 명령과 같은 이름, 같은 키
왼쪽 화살표: 선택 항목이 속한 글타래 접기
*: 모든 글타래 펼치기(보기 > 글타래에도 있음). \: 모든 글타래 접기(보기 > 글타래에도 있음)
보기 > 글타래 > 모두 / 주시 중인 글타래 / 무시한 글타래로 표시할 글타래를 거릅니다. 모두로 돌아가면 항상 모든 메시지가 다시 나타나며, 이 필터는 폴더에서 아무것도 제거하지 않습니다

열린 메시지
Alt+A: 이 메시지 보관. 본문(텍스트 또는 HTML)에 실제로 키보드 포커스가 있을 때만 작동하며, 다른 곳에서는 Alt+A가 평소처럼 계정 메뉴를 엽니다
Ctrl+R: 회신
Ctrl+Shift+R: 모두 회신
Ctrl+L: 전달
Ctrl+Delete 또는 Ctrl+D: 이 메시지를 지운 편지함으로 이동. HTML 메시지에 포커스가 있을 때 Delete만 누르면 화면 낭독기가 가져가는 경우가 많습니다. Shift+Delete는 영구 삭제합니다
Ctrl+Shift+Page Down: 이 글타래의 다음 메시지. Ctrl+Shift+Page Up: 이전 메시지. 다른 탭을 열지 않고 현재 탭을 바꾸므로 한 번에 메시지 하나만 열려 있습니다. 마지막 메시지(뒤로 갈 때는 첫 메시지)에서는 이를 알리고 묻습니다. 같은 키를 다시 누르면 메시지를 닫고 글타래를 마치며 메시지 목록으로 돌아갑니다(Ctrl+Page Up/Down은 그대로 탭을 전환합니다)
Ctrl+B: 메시지 보기 전환(텍스트/HTML)
Ctrl+P: 인쇄
Ctrl+Shift+P: 인쇄 미리 보기
Ctrl+S: 다른 이름으로 메시지 저장
Ctrl+U: 보낸 사람 이름과 주소 읽기
Ctrl+Shift+U: 보낸 사람 읽고 주소 복사
Ctrl+Shift+I: 이 메시지의 원격 콘텐츠 표시
Ctrl+Shift+=: 메시지 글꼴 크게
Ctrl+Shift+-: 메시지 글꼴 작게
Ctrl+Shift+0: 메시지 글꼴 크기 초기화

메시지 작성
Ctrl+Enter 또는 Alt+S: 보내기
Ctrl+S: 임시 저장
Ctrl+Shift+A: 파일 첨부
Ctrl+Shift+S: 보낸 사람에 있는 계정의 서명 넣기
Ctrl+Shift+V: 인용으로 붙여넣기
Ctrl+Shift+W: 단어 수
Ctrl+Shift+P: 보낼 모습 그대로 메시지 미리 보기
Esc, Ctrl+W 또는 Ctrl+F4: 작성 탭 닫기. 저장하지 않은 내용이 있으면 먼저 묻고 임시 저장, 버리기, 계속 편집을 제시합니다
아래 명령은 모두 작성 메뉴에도 있으며, 메시지 본문에 포커스가 있어도 Alt+C로 열 수 있습니다

작성 중 서식
Ctrl+B: 굵게
Ctrl+I: 기울임꼴
Ctrl+Shift+X: 취소선
Ctrl+Shift+8: 글머리 기호 목록
Ctrl+Shift+7: 번호 매기기 목록
Ctrl+Shift+9: 인용
Ctrl+Shift+6: 코드
Ctrl+Alt+1: 제목
Ctrl+K: 링크 삽입
Ctrl+Shift+K: 커서 위치에 적용된 서식 읽기
Ctrl+Shift+M: 메시지 본문을 포함해 포커스가 어디 있든 서식 메뉴 열기

작성 중 맞춤법
Ctrl+Shift+F7: 맞춤법 검사
Ctrl+Shift+F9: 다음 맞춤법 오류로 이동
Ctrl+Shift+F8: 검사가 멈춘 단어를 사전에 추가

두 곳에서 쓰는 같은 키
Ctrl+S: 작성 중에는 임시 저장, 열린 메시지에서는 다른 이름으로 메시지 저장
Ctrl+B: 작성 중에는 굵게, 열린 메시지에서는 텍스트/HTML 전환
Ctrl+Shift+P: 작성 중에는 미리 보기, 열린 메시지에서는 인쇄 미리 보기
Alt+A: 보관. 단, 메시지 본문에 키보드 포커스가 있을 때만. 그 밖의 모든 곳에서는 계정 메뉴를 엽니다

진단
Ctrl+Shift+F12: 단축키 진단. 작성 탭에서 누른 키 조합마다 디버그 로그에 한 줄을 써서 키가 실제로 무엇을 받았는지 확인할 수 있게 합니다. 기본적으로 꺼져 있으며 같은 키로 다시 끕니다. 두 경우 모두 상태를 읽어 줍니다
